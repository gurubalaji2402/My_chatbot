# Friendly NLP Chatbot

This is a simple **Friendly NLP Chatbot** project built using **HTML, CSS, JavaScript**, and **JSON**.

The chatbot responds to user messages based on predefined intents stored in `intents.json`. It can handle personal and friendly conversations such as greetings, motivation, hobbies, friendship, compliments, and more.

This project is beginner-friendly and demonstrates the basic concept of **intent-based chatbots**.

---

## Features

- Friendly conversational chatbot
- Intent-based response system
- Responses loaded from `intents.json`
- Interactive web UI
- Beginner-friendly structure
- Easy to customize tags and responses
